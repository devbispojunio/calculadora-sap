# Política de segurança

Este é um projeto pessoal e não oficial (fork da Windows Calculator, sem vínculo com a Microsoft ou a SAP SE).

Para reportar uma vulnerabilidade, abra uma [issue](https://github.com/devbispojunio/calculadora-sap/issues) sem detalhes sensíveis ou entre em contato com o mantenedor pelo GitHub (@devbispojunio).

Falhas que afetem o produto original da Microsoft devem ser reportadas ao [repositório oficial](https://github.com/microsoft/calculator).
